WSJTX Bridge Helper

A lightweight companion binary that bridges WSJTX to RigControl Web. Runs on your local machine alongside WSJTX — no Node.js or other runtime required.

Download

Choose your platform

Linux

x86_64 binary

macOS

Universal binary

Windows

x86_64 .exe

After downloading, run the helper from a terminal: 

# Linux / macOS
chmod +x wsjtx-bridge-linux    # (or wsjtx-bridge-mac)
./wsjtx-bridge-linux

# Windows
wsjtx-bridge.exe

See the WSJTX Integration Guide for full setup instructions.
